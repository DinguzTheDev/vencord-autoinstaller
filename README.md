## 🚀 What is Vencord Auto-Installer?

**Vencord Auto-Installer** is a simple utility from the **Dinguz Utils** collection that makes installing Vencord quick and straightforward.

Instead of manually going through installation steps, simply launch the installer and let it handle the process.

### ⚡ One click. One installation. Done.

The goal is to make getting started with Vencord as fast and painless as possible.

## 🧩 What is Vencord?

[Vencord](https://vencord.dev/) is a Discord client modification with a large collection of built-in plugins, custom themes, CSS support and additional customization features.

Vencord describes itself as:

> The cutest Discord client mod

It is an independent open-source project maintained by the Vencord community. The official Vencord project provides its own installers and documentation.
